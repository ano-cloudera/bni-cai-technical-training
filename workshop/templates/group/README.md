## Run order

1. Open a Python 3.10 session and load the settings: `set -a; source config/group.env; set +a` (or let each
   notebook read it for you).
2. Run notebooks **00 to 12 in order**.
3. **Notebooks 01 and 02 are trainer-only.** Read them, but do not start a model server: the trainer runs the one
   shared vLLM endpoint.
4. Use the shared endpoints (model, Qdrant, Phoenix, LiteLLM). Do not create your own.
5. Finish with notebook 12 and the shared Workshop Portal.
