# Agent Studio Workshop Flow

Place this module after LiteLLM and guardrails on Day 2. Connect Agent Studio to the shared OpenAI-compatible endpoint, recreate the simplified analyst and insight flow, and test drafts per group. Select one workflow only for final publish. Publishing additional workflows creates additional Model and Application workloads, so it is not part of the participant path.

Use synthetic data tools only. Store endpoint credentials in the environment or service account configuration. Record the published workflow URL in the trainer inventory, not in source control.
